# BuildGuard Development Instructions

BuildGuard is a construction project compliance platform.

Before changing code, read:

- README.md
- docs/project-prompt.md
- docs/architecture.md
- docs/roadmap.md

Rules:

- Work on one milestone at a time.
- Do not start the next milestone until I say `next`.
- Explain Symfony concepts and Laravel equivalents when useful.
- Add automated tests for every feature.
- Do not commit secrets.
- Use `.env.example` instead of `.env`.
- Use Docker for local development.
- Use modular Symfony architecture.
- Use secure defaults and input validation.
- Make message consumers idempotent.
- Update documentation after each milestone.
- Explain every changed file.
- Report commands used to verify the work.
